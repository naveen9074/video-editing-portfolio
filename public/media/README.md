# Portfolio media

- `profile/` — add your portrait as `profile.jpg`; set `profileImage` in `src/data/projects.ts` to `/media/profile/profile.jpg`.
- `posters/` — add compressed JPG/WebP poster frames here. Update a project's `poster` path in `src/data/projects.ts`.
- `videos/` — add optimized MP4s here and use a URL such as `/media/videos/my-edit.mp4`. Larger files are better hosted with a direct MP4 URL on a video/CDN host.
- `branding/` — optional logo or supporting graphics.

The SVGs in `posters/` are abstract temporary artwork, not project samples. Replace them when adding your own work.
